REAPER Scrolling Chords (ChordPro)

State

OFF: Run the companion script to initialize.

Installation

Set this page as REAPER web interface, with menu Options › Preferences › Control/OSC/Web.

Start

  1. Connect to the web interface using a web browser on a device in your local network.
  2. Run the companion script to send the lyrics from the item notes of the "Lyrics" track to the web interface.

Companion Script

  1. In REAPER, load the script with Actions › Show action list › New action › Load ReaScript…:
    Convert Lyrics track items notes for scrolling web browser interface.lua
  2. Run it once: it keeps running in the background, following the active project tab and your edits.
  3. To start it with REAPER, copy __startup.lua to the REAPER Scripts folder.
